; NOTE: with the element-aware grammar, `{@attach …}` written *as an element
; attribute* is now absorbed into the surrounding `html_open_tag`'s opaque
; `element_attributes` blob rather than surfaced as a standalone
; `svelte_at_attach` node. (A bare `{@attach …}` not inside a tag still parses
; as `svelte_at_attach`.) This is a known limitation of treating attributes as
; opaque: the `{@attach}` body no longer gets its own JS injection.
